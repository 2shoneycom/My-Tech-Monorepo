## 소개

홍익대학교 컴퓨터공학과 졸업 프로젝트로, 사용자의 게임 플레이가 실시간으로 DB 및 웹사이트와 동기화되는 서비스를 제작했다.

## 링크

- GitHub (게임): [PokerProject](https://github.com/2shoneycom/PokerProject)
- GitHub (웹사이트): [PokerProjectWebSite](https://github.com/2shoneycom/PokerProjectWebSite)
- 데모 영상: [YouTube](https://www.youtube.com/watch?v=hU301tzVMGo&t=3s)
- 웹사이트: [Poker House](https://2shoneycom.github.io/PokerProjectWebSite/)

## 개발 프로세스

소프트웨어 공학의 개발론을 따라 "요구사항 정의 → 사이트맵 → 와이어프레임 → 클래스/커뮤니케이션/시퀀스 다이어그램 설계 → 개발"의 순서로 진행했다.
